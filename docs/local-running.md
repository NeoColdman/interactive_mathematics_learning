# 本地运行与离线使用

0.5.0共包含28个学习项目：第一章12个核心项目、第二章加减法及乘除基础14个项目，以及合并给定同类项、角平分线求角。数学活动与选学、其余内容仍按后续计划扩展。记录保存在运行服务的电脑，电脑浏览器和同一家庭网络中的 iPad 访问同一份记录。

## 首次准备

1. 把完整项目解压到电脑的本地文件夹。不要直接在压缩包预览中启动，也不要只复制启动文件。
2. 安装适合这台电脑的 **Node.js 24 或 22**，下载入口为 [Node.js 官网](https://nodejs.org/)。安装属于首次准备；程序不会自行安装软件、修改系统设置或下载依赖。
3. 保留 `server.mjs`、`domain`、`public`、`vendor` 和 `scripts` 等项目文件。运行不需要 npm 安装，也不依赖教材 PDF。

如由熟悉电脑的人提供运行时，也可将该电脑适用的 Node 放在以下位置。启动脚本优先选用这些位置中可运行且版本为22或24的程序，然后查找系统已有的 Node；macOS 还会检查通常的 nvm 安装位置。

| 系统 | 项目内可选运行时位置 |
| --- | --- |
| macOS | `runtime/bin/node` 或 `runtime/node` |
| Windows | `runtime/node.exe` 或 `runtime/bin/node.exe` |

源码包不捆绑未经核验的运行时。macOS 与 Windows 的 Node 程序不能互换。

## 日常启动和停止

| 系统 | 启动入口 |
| --- | --- |
| macOS | 双击项目里的 `start.command` |
| Windows 10 / 11 | 双击项目里的 `启动学习.cmd` |

启动后保留终端窗口。浏览器会在服务准备好后自动打开；没有自动打开时，手动访问窗口显示的电脑地址，通常是 **http://127.0.0.1:3210**。从其他文件夹启动、项目路径含空格或中文时，脚本仍按自身所在文件夹寻找程序。

停止时在运行窗口按 **Control+C / Ctrl+C**，再关闭窗口。只关闭浏览器不会停止服务。服务停止或电脑休眠后，平板暂时无法连接；重新启动后原来的学习记录仍在。

如果窗口提示端口已被使用，先检查是否已有一个学习服务窗口正在运行。可以直接使用已有窗口显示的地址，或停止原服务后再启动；不要反复打开多个窗口。

## iPad 访问

1. 让电脑与 iPad 连接可以相互访问的同一家庭网络。
2. 在电脑页面查看“平板访问”的地址和二维码，用 iPad 扫码后在 Safari 打开；也可手动输入该地址。
3. 在 iPad 选择相同的学习档案，即可看到电脑保存的进度、练习与错题。

`127.0.0.1`和`localhost`只供运行服务的电脑自己访问，不能填到 iPad 里。页面显示多个平板地址时，可尝试其他地址；部分网络会将访客设备隔离。首次出现系统网络访问提示时，按家庭网络的实际使用需要处理。

二维码由电脑内置的代码生成，不调用外部二维码网站。它只包含本机服务地址，不包含学习记录。

## 离线与学习档案

首次准备好 Node 和完整项目后，教学、公式、图形、练习生成、判题、提示、解析、二维码及记录保存均在本地完成，不需要外网或云账号。路由器和设备之间的家庭网络仍须保持可用。

默认档案为“我的学习”，可在页面添加和切换家庭档案。不同档案的进度与错题分开；它们是家庭内部的选择入口，不是带密码的账户。

每轮5题，3基础题、2变式题。首次正式提交正确且此前没使用本题提示或解析，才计入独立正确；全部完成后，至少4题独立正确显示“本轮达标”。订正、提示后完成和查看解析完成不会改写首次成绩。原题复习只更新复习记录；“再来一组”建立新轮次。

## 数据位置、备份和更新

默认记录目录独立于项目文件夹：

| 系统 | 默认位置 |
| --- | --- |
| macOS | `~/Library/Application Support/InteractiveMathLearning` |
| Windows | `%APPDATA%\InteractiveMathLearning`，一般位于用户的 `AppData\Roaming` 下 |

实际位置也会显示在服务启动窗口。主要文件为 `learning.json`，保存前的备份为 `learning.json.bak`。程序通过临时文件写入后替换主文件；发现主文件损坏时会尝试读取备份，并在服务窗口说明情况。

- 手工备份：先停止服务，再复制**整个记录目录**到另一个安全位置。
- 更新应用：先停止服务，保留记录目录，替换应用文件后重启。不要用旧版本、其他电脑或空白档案的数据文件覆盖现有记录。
- 换电脑：停止两端服务，先备份，再将完整记录目录复制到新电脑对应位置。macOS 与 Windows 的应用兼容不代表两台电脑会自动同步。
- 记录无法读取时，保留主文件和备份，不要删除后反复重建；先查看窗口中的具体提示。

从0.1.0—0.4.0更新到0.5.0无需导入或转换学习记录。默认记录目录与记录格式保持一致，旧轮次和错题使用保存的原题条件，首次成绩继续保留。请完整替换应用文件，避免只替换页面导致题目与服务版本不一致。

## 常见情况

| 现象 | 处理方式 |
| --- | --- |
| 显示没有可用 Node | 完成首次安装，确认版本为22或24后再启动；脚本不会自动安装 |
| macOS 提示启动文件没有执行权限 | 源码包保留了执行位，但个别解压工具可能丢失；可由熟悉电脑的人为 `start.command` 恢复执行权限 |
| 浏览器没有自动打开 | 使用服务窗口打印的电脑地址；浏览器打开失败不影响已经运行的服务 |
| iPad 无法连接 | 保持电脑开机与服务运行，使用平板地址，检查设备是否在可互访的家庭网络 |
| 页面显示连接或保存失败 | 保留当前页面，恢复与电脑的连接后重试；不要把未确认保存的操作当作已保存 |
| 更新后看不到原记录 | 核对是否仍是同一台运行电脑、同一系统用户、同一记录目录与学习档案 |

## 供维护者使用

以下操作不是家长日常启动的必要步骤。

在项目目录运行全部自动化测试：

```sh
node --test
```

HTTP 集成测试只监听本机随机端口，并把所有记录放入临时目录，结束后关闭服务并清理。测试不读写家长的默认学习记录。

直接运行服务：

```sh
node server.mjs
```

可配置环境变量：

| 变量 | 默认值与用途 |
| --- | --- |
| `PORT` | `3210`；更换端口时，浏览器和 iPad 地址也随之改变 |
| `MATH_HOST` | `0.0.0.0`；改为 `127.0.0.1` 时仅当前电脑可访问 |
| `MATH_DATA_DIR` | 未设置时使用上面的系统用户目录；可指定独立的绝对路径进行演示或测试 |
| `MATH_NO_BROWSER` | 设为 `1` 时，双击启动脚本不自动打开浏览器，便于维护验证 |

生成离线源码包：

```sh
node scripts/package.mjs
```

默认输出为 `dist/interactive-math-learning-offline-source.zip`。可使用 `--output 路径`指定输出位置，或用`--dry-run`先查看清单。包中包含应用源码、本地资源、启动脚本、文档和测试；排除学习数据、教材、`node_modules`、运行时、缓存、日志、测试临时目录及已有输出。解压后仍须准备匹配电脑的 Node 22或24。

## 实机验证范围

支持目标为 macOS、Windows 10/11 和 iPad Safari。自动化测试可以验证服务接口、记录持久性、判题状态流和本地资源；它不能代替 Windows 双击启动、系统网络提示、iPad 扫码/触控与 Safari 的实际设备验收。未完成的设备检查应按[首阶段验收清单](pilot-acceptance.md)逐项记录，不能据自动化通过宣称所有设备均已实测。
