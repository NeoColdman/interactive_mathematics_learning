## 2. 数学内容核对清单

### 负数比较

- [ ] 数轴方向、点位置、标记数值和比较符号一致。
- [ ] 正确体现两个负数绝对值越大反而越小。
- [ ] 分数与小数的比较计算正确，等值边界不会误判。
- [ ] 提示纠正常见误解，例如把绝对值大小直接当成负数大小。
- [ ] 练习含新数据，不靠记住学习示例的答案通过。

### 合并同类项

- [ ] 合并前后字母及其指数保持不变。
- [ ] 系数的正负、1与-1、分数、抵消为0处理正确。
- [ ] 多字母项的书写顺序不影响数学上正确的答案。
- [ ] 判分检查“已合并”的目标形式，不能把未合并原式当成目标完成。
- [ ] 已给定同类项与后续“识别同类项”目标边界清楚。

### 角平分线求角

- [ ] 图中角名、顶点、边、平分线与文字条件一致。
- [ ] 整体角等于两个子角之和，已知平分条件时两个子角相等。
- [ ] 改变图形朝向、开口与比例后，倍半关系保持正确。
- [ ] 新题能区分题目所求是整体角还是子角。
- [ ] 该样板不混入度分秒换算或多条平分线等额外考核目标。

## 3. 学习与练习流程核对

- [ ] 三个项目都有明确目标、引导操作、结果观察、规则和示例。
- [ ] 可自由探索与重置；电脑鼠标和 iPad 触控均可完成关键操作。
- [ ] 可直接进入练习，也可从练习返回学习。
- [ ] 每轮5题，3道基础、2道变式，题目与当前小目标匹配。
- [ ] 学习支架撤去后，题目仍保留理解题意所需图形与条件。
- [ ] 每题提交后即时反馈，可提示、重试并主动查看分步解析。
- [ ] 首次正确且未用提示/解析才计入独立正确数，至少4题为本轮达标。
- [ ] 首次错误后订正不会改写本轮首次成绩。
- [ ] 原错题重做显示复习结果；新题另开五题轮次，原轮成绩保留。
- [ ] 空输入、不可判定输入、重复点击及拖动过程处理明确。
- [ ] 轮次结果分别展示首次作答、求助及订正情况。
- [ ] 可返回学习、订正错题、再来一组；达标后仍可继续练习。
- [ ] 新题参数经过校验，题干、答案、提示与解析来自同一套题目条件。

## 5. 孩子试用：观察是否帮助做题

试用者由用户安排，为其孩子。家长协助启动，主要观察孩子自主使用过程。试用记录可以用纸笔或简单表格，不新增专门的前测系统。

### 建议过程

1. 每个目标先选少量同难度题，了解原有表现，记录是否会做及是否求助。
2. 孩子完成样板学习，记录卡住位置、误解、需要家长额外说明的地方。
3. 使用未见过的同难度题检验独立作答；保留首次结果和求助情况。
4. 让孩子重做错题或再练一组，观察是否理解反馈并能订正。
5. 家长与孩子简短交流：哪里有帮助，哪里难用，哪些操作有趣或令人分心。

前后题应保持目标和难度可比、题目不同。常规一轮5题仍沿用产品计分规则；试用前的小测只用于了解起点，不与正式成绩混合。
