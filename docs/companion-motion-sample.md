## 派生资产与来源

原 `hatsune_miku_v6.glb` 没有骨架、蒙皮、动画或面部 morph。项目在独立派生文件中新增了 27 个真实关节、一个共享 skin、31 个绑定网格、七条动作和 blink/smile 表情目标。双马尾每侧四个关节，角色左右按照 +Z 面向前、+X 为角色左侧约定。

原始模型的 124 个几何 accessor 字节、UV、法线、索引和材质分配保持不变。新增蒙皮权重、关节索引、逆绑定矩阵、表情增量与动作轨道均为本项目制作，不冒称原文件已有。静态 GLB 与用户提供的原文件继续保持字节一致。

| 文件 | 用途 |
| --- | --- |
| `scripts/rig-companion.py` | 根据实测部件与解剖位置生成骨架、蒙皮和可追溯证据 |
| `scripts/author-companion-motion.py` | 追加动作轨道与面部增量，保留原始几何与已有绑定数据 |
| `public/companion/hatsune_miku_v6-rigged.glb` | 带真实骨架和蒙皮的中间派生文件 |
| `public/companion/hatsune_miku_v6-animated.glb` | 动作页面实际加载的动作与表情派生文件 |
| `public/companion/load-animated-miku.js` | 连接真实骨骼与表情轨道的控制器 |
| `scripts/verify-companion-motion.mjs` | 实际浏览器绑定、顶点变形、切换与暂停等验证 |
| `scripts/verify-companion-face.mjs` | 最后一次表情修整的顶点/法线、正面/侧面截图与响应式布局检查 |

模型来源、作者与许可标注保留在 `public/companion/ATTRIBUTION.md` 及页面底部。运行资源全部本地提供，预览贴图最大边 2048，主视图与角落示例共用一个 WebGL 上下文。

待机循环播放，其余动作播放一次后回到待机。七条动作均设计为首尾姿态相合，因此数值上可以循环；产品只循环待机。动作意图是作者设定，不当作算法已证明的情绪识别结果。

新操作通过当前姿态快照与新轨道插值平滑衔接，避免积压旧动作。气泡约五秒收起，场景名保留。提供暂停/继续、恢复原始展臂姿态、减少动作、四视角与背景切换。减少动作时保留文字、恢复静态姿态并停止持续重绘；页面隐藏时暂停。

## 验证与边界

骨架读取、原几何字节一致性、蒙皮属性结构、动作特征与双脚站姿已有机器检查。闭眼形变修整前的浏览器批次已实测七类动作各 25 个真实顶点姿态、42 组有序切换，以及关节、表情和头发的实际变化；暂停、减少动作与原姿态恢复也有对应测量。该批次记录保留在 `.img2threejs/imported-glb/animation/validation/`。

最后一次修整只改表情增量：闭眼睫毛按闭合面部表面贴合，表情增加法线增量，并保留原模型柔和的面部法线场。原始法线与其他几何字节仍保持不变。最终资产核对见 `.img2threejs/imported-glb/animation/final-asset-integrity.json`；七条动作的骨架结构与 7×25 个采样姿态和修整前一致，189 条关节轨迹及 77 条表情权重轨迹与作者公式逐 float32 匹配。

修整后的独立浏览器复核见 `.img2threejs/imported-glb/animation/validation/face-final/report.json`：11 个表情网格分别检查六组 blink/smile 权重组合，所有实际顶点与法线均为有限值、无零长度法线；保留正面与 35° 的睁眼/闭眼截图。820×1180 与 375×812 布局均无横向溢出，七个场景按钮完整显示。闭眼仍是基于原开眼网格的简化形变，近距离的眼线与眼睑过渡需要用户试用评判，不作为精细面部绑定已验收的结论。

现有角色插件实测结论为 **10 项 pass、G2 fail、G10 unevaluated**，并未通过全部 12 项门槛。G2 要求每个网格每帧至少采样 64 个独立顶点，而原模型的两个小网格分别仅有 48 与 34 个顶点；已穷举它们的实际顶点，有限性检查通过，非有限值数量为 0，但仍无法满足该项最低数量要求，因此保留 fail，不复制顶点补数。G10 的背景裂缝与折痕像素完整性基线尚未建立，保持 unevaluated；截图、骨骼计数或其他通过项均不能替代它。

原生页面隐藏的设备验证尚未完成。旧批次保留了模型已完整加载后的资源请求中断观察；最终加载器改用原生响应直接读取，避开 FileLoader 的中间进度流，最终定向复核的失败请求、HTTP 错误、脚本错误与外网请求均为 0。保留旧观察，不把有限的一次复核解释为所有设备都不再出现。截图时的 GPU ReadPixels 提示单独保留，不当作应用错误。闭眼修整前的结果与边界汇总见[修整前验证摘要](../.img2threejs/imported-glb/animation/validation/pre-face-revision-summary.md)。

加载器调整后的最后回归记录在 `.img2threejs/imported-glb/animation/validation/final-smoke/report.json`：静态原姿态仍为 31 个网格、13 张贴图，动作页为 27 个关节、31 个绑定网格与七条动作；七个场景按钮及减少动作开关均可用，脚本错误、失败请求与 HTTP 错误为 0。应用内预览也已实际打开并点验鼓励场景和减少动作开关。离线文件收集包含动作页、加载器、派生资产、13 张贴图、本地 Three.js 和来源标注；新增 JavaScript 语法检查通过。

没有手指关节、口型同步或自由语音；裙子主要跟随髋部，样板以站立手势为主。实际 iPad Safari 性能与更大幅度动作的衣服变形仍需设备试用及后续修整。真实学习流程接入前，应先完成样板确认和未完成的生产验收。
