## 1. 怎样阅读项目表

每个核心项目以一个可以练习检验的目标组织，均配“交互学习＋练习”。表格列出：

- **ID**：供内容、练习、进度和错题引用的项目标识。
- **可检验目标**：学生最终应会完成的任务。
- **交互学习设想**：为该目标服务的可视化或操作建议。
- **练习验证**：用什么任务检验是否会做，包含脱离教学辅助的新题。
- **前置与页码**：补学关系和教材追溯位置。

同一目标的整数、小数、分数或不同生活情境通常作为变式，不重复开项目。共用一个画板也不合并各自的学习目标和练习记录。

核心项目、活动/实践子项目、选学登记采用不同统计口径。活动会复用核心知识，选学登记中也可能包含尚待细分的任务，因此三类数字不直接相加为“不重复知识点总数”。

## 5. 可复用的交互模型

复用对象是画板和操作能力，项目仍按独立目标组织。

| 交互模型 | 可承载的目标 | 内容设计重点 |
| --- | --- | --- |
| 数轴与有向移动 | 数轴对应、相反数、绝对值、负数比较、加减、两点距离 | 同时表示位置、方向与距离，避免把距离当成带符号数 |
| 带符号数卡与算式步骤 | 运算律、符号、顺序、乘方、近似处理 | 变形与结果保持数学一致，展示当前可执行步骤 |
| 代数项与数量关系板 | 列式、求值、项的识别、合并、去括号 | 符号部分与系数明确对应，分数及负系数不被误画成普通正整数件数 |
| 等式同步变换板 | 等式性质、移项、方程求解 | 展示两边同一操作；负数可用符号板解释，不依赖真实砝码直觉 |
| 路程/工作量/费用模型 | 正反比例、行程、工程、配套、费用比较 | 可操作的量与文字条件一致，明确总量、变化量和相等关系 |
| 几何观察与折叠 | 方向观察、展开图、点线面体运动 | 图形连接、遮挡和观察方向正确，保留可预测后验证的过程 |
| 线段与角工作台 | 量取、比较、和差、等分、余补关系 | 操作精度、数学条件和视觉标记一致，变换朝向不改变关系 |
| 位值与进位格 | 科学记数法、近似数、进位制 | 分清位值、指数、记法与换算约定 |

## 6. 内容依赖与扩展顺序建议

主干可概括为：有理数认识与运算 → 代数式 → 整式加减 → 等式性质与解方程 → 实际问题建模。几何分支以小学图形经验为基础，线段和角的计算会调用已学数与代数技能。

该依赖用于提示补学和安排制作顺序，学生仍可自由选学。第一阶段先完成已选样板；第二阶段按依赖批次扩展，数学活动和综合实践在前置具备后汇合。实际批次依据孩子试用和用户确认调整。

## 7. 覆盖审阅规则

整册扩展时，每个上线项目都应能追溯到教材目标，并核对以下内容：

1. 该目标是否已经由另一项目覆盖，是否只是题型或情境变化。
2. 学习部分是否让学生操作关键关系，图形和符号是否一致。
3. 练习是否直接检验该目标，是否包含未见过的同难度变式。
4. 提示、解析、答案形式和参数边界是否完整。
5. 前置和综合活动是否有明确映射，暂未上线内容是否清楚标示。
6. 正文目标、选学拓广与产品补充知识是否区分。
