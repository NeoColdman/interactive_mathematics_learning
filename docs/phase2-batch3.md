## 本批范围

| ID | 可检验目标 | 交互学习重点 | 练习验证重点 |
| --- | --- | --- | --- |
| C2-01 | 正确计算两个有理数的和 | 起点、带方向的移动和终点；先预测符号再观察 | 同号、异号、互为相反数、加0，整数、小数、分数 |
| C2-02 | 不计算具体和，判断所加数让原数变大、变小或不变 | 固定起点，只改变第二个加数，比较起点和终点 | 依据第二个加数的正负或0判断变化，避免按起点符号猜结果 |
| C2-03 | 利用加法交换律和结合律，选择分组并计算 | 带符号加数整体重排、选择分组，对照等价变形 | 同时检验分组步骤、运算律和结果，不能只检验最终和 |
| C2-04 | 用标准量×份数＋偏差和求实际总量 | 实际量、统一标准与偏差的对照 | 区分偏差和与实际总量，标准与份数明确给定 |
| C2-05 | 将减去有理数转为加其相反数并计算 | 认清减数，选择相反数，数轴验证转化 | 负数作减数、0作被减数、小数分数与温差任务 |
| C2-06 | 将加减混合式化为带符号的和并计算 | 运算符号与数的符号分清，整张带符号卡保留 | 正确转换、等价的省略写法、分组和最终值 |
| C2-07 | 由两点数值计算数轴距离，并检验表达式 | 先猜表达式，再改变端点、交换顺序和跨过原点验证 | 同侧、异侧、交换端点、重合、分数小数；距离非负 |
