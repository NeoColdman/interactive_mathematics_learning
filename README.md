# 交互学数学

面向七年级学生家庭自主学习与复习的交互数学网页项目。

0.5.0包含第一章12个核心项目、第二章加减法及乘除基础14个项目，另保留合并给定同类项与角平分线求角，共28个学习项目。数学活动与选学、第二章其余内容及后续章节仍按整册规划分批扩展。

首次准备好 Node.js 24 或22后，日常双击启动即可使用，无需安装 npm 依赖：

- macOS：双击 `start.command`。
- Windows 10/11：双击 `启动学习.cmd`。

保留运行窗口，浏览器会自动打开。同网 iPad 可使用页面中的平板地址和二维码访问；停止时在运行窗口按 Control+C / Ctrl+C。教学、练习和记录均在本地完成。

学习内容覆盖有理数的认识与比较、加减法、标准偏差求总量、数轴两点距离、乘除基础、倒数、乘积符号、加法与乘法运算律及规范分数；另保留合并给定同类项与角平分线求角。

运行目标：macOS、Windows 10/11 本地运行，电脑浏览器与同网 iPad 访问；首次准备后日常离线可用。具体设备版本、逐项测试结果与学习效果记录见验收清单；本次通过确认未细分这些结果。

维护者可用 `node --test`运行自动化测试，使用 `node scripts/package.mjs`生成不含教材与学习记录的离线源码包。该包不捆绑运行时。
